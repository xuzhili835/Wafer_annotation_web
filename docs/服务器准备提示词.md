> 推送任意一次代码就会自动完成后续所有部署。第一次准备只需发给服务器 AI 这一段:

---

请帮我在这台服务器上为一个 FastAPI 标注站做好一次性准备。只做准备与汇报,不要启动常驻服务以外的改动,遇到不确定先汇报再动。

## 背景
- 应用:Wafer_annotation_web,FastAPI + SQLite,单进程,内存占用很小(2核2G 没问题)。
- 监听 127.0.0.1:8100,由 nginx 反代域名 `wafer.echeng.xyz`(Cloudflare 已代理,参考本机已有的 echeng.xyz 站点配置写法即可)。
- 代码将来由 GitHub Actions rsync 到 `/opt/wafer-label/app/` 并执行 `deploy/deploy.sh`(自动备份 db、装依赖、重启 systemd、健康检查)。

## 请依次执行
1. 建目录并赋权(假设部署用户是 ubuntu,与现有站点一致;若不同请告诉我实际用户名):
   ```bash
   sudo mkdir -p /opt/wafer-label/{app,data,backup,venv}
   sudo chown -R ubuntu:ubuntu /opt/wafer-label
   ```
2. 建虚拟环境并预装依赖:
   ```bash
   python3 -m venv /opt/wafer-label/venv
   /opt/wafer-label/venv/bin/pip install -i https://mirrors.aliyun.com/pypi/simple/ fastapi "uvicorn[standard]" pillow
   ```
3. 写 systemd 服务 `/etc/systemd/system/wafer-label.service`:
   ```ini
   [Unit]
   Description=Wafer annotation web (FastAPI)
   After=network.target

   [Service]
   User=ubuntu
   WorkingDirectory=/opt/wafer-label/app
   Environment=WAFER_DATA_DIR=/opt/wafer-label/data
   Environment=WAFER_DB=/opt/wafer-label/data/labels.db
   Environment=WAFER_TOKENS=/opt/wafer-label/data/tokens.txt
   Environment=WAFER_HOST=127.0.0.1
   Environment=WAFER_PORT=8100
   ExecStart=/opt/wafer-label/venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8100
   Restart=always
   RestartSec=3

   [Install]
   WantedBy=multi-user.target
   ```
   然后 `sudo systemctl daemon-reload`(先不 start,等数据就位后由部署脚本拉起)。
4. nginx 新增 server 块(参考现有 echeng.xyz 的写法):`wafer.echeng.xyz` →
   `proxy_pass http://127.0.0.1:8100;`,带上
   `proxy_set_header Host $host; proxy_set_header X-Real-IP $remote_addr; proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for; proxy_set_header X-Forwarded-Proto $scheme;`
   以及 `client_max_body_size 10m;`。改完先 `sudo nginx -t` 通过再 reload。
5. HTTPS:该域名走 Cloudflare 代理。请检查现有站点的证书是怎么配的(latest certbot 还是 CF 源站证书),给 wafer.echeng.xyz 配同样的方式;如果 certbot 需要 DNS 验证或我操作,先汇报方案。

- 上述每一步的执行结果;
- 9000 以上端口占用情况(确认 8100 空闲)。
