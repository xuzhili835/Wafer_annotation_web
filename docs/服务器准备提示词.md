请帮我在这台服务器上为一个 FastAPI 标注站做好一次性准备。这台服务器的目录结构一直保持得很整齐,所以请**先汇报、后动手**:

## 第一步:先汇报,不要创建任何东西
1. `ls /opt` 与 `ls /home/ubuntu`(或实际部署用户的主目录),让我看到现有目录组织习惯;
2. `ls /etc/nginx/sites-enabled/`(或 conf.d),列出现有站点;
3. `python3 --version`、`nginx -v`;
4. 确认 8100 端口空闲(`ss -ltnp | grep 8100` 无输出即可)。

## 第二步:按汇报结果选安装根目录
- **默认方案:`/opt/wafer-label`** —— 全新独立目录(app 代码 / data 数据 / backup 备份 / venv 环境),不会碰任何现有站点, 目录总量很小;
- 如果你认为按现有惯例放别处更合适(例如 `/home/ubuntu/apps/wafer-label`),可以直接采用,
  但**必须在汇报里写明最终根目录路径**,后续配置里所有路径都以它为准;
- 确定后创建:`<根>/{app,data,backup,venv}` 四个子目录,属主给部署用户
  (`sudo mkdir -p ... && sudo chown -R ubuntu:ubuntu <根>`,用户名以实际为准)。

## 第三步:虚拟环境
```bash
python3 -m venv <根>/venv
<根>/venv/bin/pip install -i https://mirrors.aliyun.com/pypi/simple/ fastapi "uvicorn[standard]" pillow
```

## 第四步:systemd 服务 `/etc/systemd/system/wafer-label.service`
(若根目录不是 /opt/wafer-label,下面所有路径同步替换)
```ini
[Unit]
Description=Wafer annotation web (FastAPI)
After=network.target

[Service]
User=ubuntu
WorkingDirectory=<根>/app
Environment=WAFER_DATA_DIR=<根>/data
Environment=WAFER_DB=<根>/data/labels.db
Environment=WAFER_TOKENS=<根>/data/tokens.txt
Environment=WAFER_HOST=127.0.0.1
Environment=WAFER_PORT=8100
ExecStart=<根>/venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8100
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```
然后 `sudo systemctl daemon-reload`(先不 start,数据就位后由部署流程拉起)。

## 第五步:nginx 站点 `wafer.echeng.xyz`
- 参照本机现有 echeng.xyz 站点的写法新增 server 块:`server_name wafer.echeng.xyz;`
- 反代:`proxy_pass http://127.0.0.1:8100;` 并带
  `proxy_set_header Host $host; proxy_set_header X-Real-IP $remote_addr; proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for; proxy_set_header X-Forwarded-Proto $scheme;`
  以及 `client_max_body_size 10m;`
- HTTPS:域名走 Cloudflare 代理。请检查现有 echeng.xyz 的证书方式(CF 源站证书或 certbot),
  给 wafer.echeng.xyz 配**同样的方式**;若需要我在 CF 后台操作(如签发源站证书),先汇报方案;
- 改完 `sudo nginx -t` 通过再 `sudo systemctl reload nginx`。
