请帮我在这台服务器上为一个 FastAPI 标注站做好一次性准备。这台服务器的目录结构一直保持得很整齐,新项目会与现有项目**并列**放置,请**先汇报、后动手**:

## 第一步:先汇报,不要创建任何东西
1. `ls /home/ubuntu`(或实际部署用户的主目录),让我看到现有项目并列结构,确认 `wafer-label` 无同名冲突;
2. `ls /etc/nginx/sites-enabled/`(或 conf.d),列出现有站点;
3. `python3 --version`、`nginx -v`;
4. 确认 8100 端口空闲(`ss -ltnp | grep 8100` 无输出即可)。

## 第二步:建项目目录(与现有项目并列)
```bash
sudo mkdir -p /home/ubuntu/wafer-label/{app,data,backup,venv}
sudo chown -R ubuntu:ubuntu /home/ubuntu/wafer-label   # 用户名以实际为准
```
- `app/` 放代码,`data/` 放图片+数据库+令牌(都在项目内),`backup/` 备份,`venv/` 环境;
- 若第一步发现 `wafer-label` 有冲突或你的项目另有惯例位置,先汇报再定。

## 第三步:虚拟环境
```bash
python3 -m venv /home/ubuntu/wafer-label/venv
/home/ubuntu/wafer-label/venv/bin/pip install -i https://mirrors.aliyun.com/pypi/simple/ fastapi "uvicorn[standard]" pillow
```

## 第四步:systemd 服务 `/etc/systemd/system/wafer-label.service`
```ini
[Unit]
Description=Wafer annotation web (FastAPI)
After=network.target

[Service]
User=ubuntu
WorkingDirectory=/home/ubuntu/wafer-label/app
Environment=WAFER_DATA_DIR=/home/ubuntu/wafer-label/data
Environment=WAFER_DB=/home/ubuntu/wafer-label/data/labels.db
Environment=WAFER_TOKENS=/home/ubuntu/wafer-label/data/tokens.txt
Environment=WAFER_HOST=127.0.0.1
Environment=WAFER_PORT=8100
ExecStart=/home/ubuntu/wafer-label/venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8100
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```
然后 `sudo systemctl daemon-reload`(先不 start,数据就位后由部署流程拉起)。

## 第五步:nginx 站点 `wafer.echeng.xyz`
- 参照本机现有 echeng.xyz 站点的写法新增 server 块:`server_name wafer.echeng.xyz;`
- 反代:`proxy_pass http://127.0.0.1:8100;` 并带
  `proxy_set_header Host $host; proxy_set_header X-Real-IP $remote_addr; proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for; proxy_set_header X-Forwarded-Proto $scheme;`
  以及 `client_max_body_size 10m;`
- HTTPS:域名走 Cloudflare 代理。请检查现有 echeng.xyz 的证书方式(CF 源站证书或 certbot),
  给 wafer.echeng.xyz 配**同样的方式**。若现有的是 CF 源站证书,它默认覆盖 `*.echeng.xyz`,
  直接复用即可;若用 certbot,请给 wafer 子域签一张(需要 DNS 验证或我操作时先汇报方案);
- 改完 `sudo nginx -t` 通过再 `sudo systemctl reload nginx`。
